Screenshots

F2 Commander

Simple file listing in the local file system. Different file properties are displayed and files are highlighted based on their nature.

Bookmarks for fast navigation to frequently-used locations. Bookmarked locations are configurable and can be in local or remote file systems.

Archives are highlighted in the file listing, and can be “navigated” into. They are treated as any other location in the file system.

A built-in command palette with fuzzy search enables the discovery of less frequently-used commands.

A remote FTP server file listing. Remote file systems are treated mostly the same as local. Here, a file preview is shown for a remote file.

Incremental search in the file listing allows to quickly jump to a file or a directory by name. Fuzzy matching makes it even faster.

Multiple files and directories can be selected to perform batch operations. Here, multiples files are being moved to Trash.

Files and directories can be previewed. File preview also highlights the syntax if it recognizes the file type.

Remote file system connection dialog. Here, a “generic” dialog exposes all known connection options for an FTP connection.

Several color themes are built-in. Here a theme switcher is shown and “Nord” theme is currently active.
