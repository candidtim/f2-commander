F2 Commander

An orthodox file manager for the modern world

Classic user experience

for a modern OS

• Orthodox two-panel interface
• Classic footer menu
• Effortless FS navigation
• Command palette
• File preview (syntax highlighting, images)
• Vi-inspired key-bindings
• Multiple color themes
• Works in Linux and macOS

Feature rich

for pragmatic users

• Extensive support for "remote" file systems (S3, Dropox, HDFS, FTP, WebDAV, and more)
• Read and extract archives (ZIP, TAR, LHA/LZH, RAR, MS CAB, 7-Zip, and more)
• Create compressed ZIP files
• Configurable Bookmarks
• View and Edit files
• And of course, classic file and directory operations
