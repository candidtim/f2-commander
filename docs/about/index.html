About the name

“F2” is a loose interpretation of “a File manager with 2 side-by-side panels”, and “Commander” is an homage to the old-school orthodox file managers.

Purpose

F2 Commander exists to bring the experience of an orthodox file manager into the world of modern computing. A “file system” can be anything that can seem to contain files and directories, (a local disk, a BLOB storage, a Cloud drive, a compressed file, etc.).

F2 Commander it is designed to be discoverable: making file systems easy to navigate, and making the F2 Commander itself obvious to use.

Status

F2 Commander is a personal project that has grown into a full-fledged file manager and is now open-sourced. As such, it may contain bugs, and is provided “as is”, without warranty of any kind.

Being a personal project means that:

  • my intent is to continue the development of the features outlined above, but the development and bug fixing may be irregularly-paced and priorities may shift;

  • my intent is to keep F2 Commander stable, but future versions may include backward-incompatible changes where that would seem pragmatic.
